# 轻压

macOS 本地文件压缩工具。支持 PDF、图片、Office、视频、音频及 ZIP 打包，始终保留原文件。

**[下载最新版本](https://github.com/798536402-a11y/filepress-releases/releases/latest)**

当前安装包适用于 Apple Silicon Mac，要求 macOS 13 或更高版本。

应用会在后台检查新版，发现更新先提示，确认后才下载并安装；压缩任务进行时会延后安装。也可以从「轻压 → 检查更新…」手动检查。

1.7 起，常见视频采用高画质两遍编码，在相近体积下保留更多细节，处理时间会比快速硬件转码更长；界面显示进度。已有充分压缩的文件可能无法继续明显缩小，有损压缩不保证完全无损。

所有压缩均在本机进行。联网仅用于检查和下载应用更新，不上传待压缩文件。更新订阅和安装包均通过签名校验。

此仓库保存安装包、更新订阅、版本说明，以及独立第三方视频引擎的对应开源源码包；不包含用户文件、签名私钥或本应用 Swift 源代码。

当前安装包尚未完成 Apple 公证，首次安装可能需在系统「隐私与安全性」中允许打开。
